# Vue.js (Enfocado principlamente al FrontEnd)

## ¿ Que es Vue.js ?

Vue.js por sí solo no es un framework Full Stack, sino una herramienta enfocada principalmente en el frontend. Es decir, se utiliza para construir interfaces de usuario interactivas y dinámicas. Su núcleo está diseñado para manejar la capa de presentación

## Caracterisiticas

Se utiliza Java Script. (Es necesario conocimientos previos en JavaScript).

Es un Framework, no es una Librería. (Es Conjunto de Herramientas que modelan un entorno de desarrollo con regalas a seguir).

Es progresivo (Es decir, en un proyecto que no tiene Vue.js, podemos implementar pequeños módulos con Vue.js sin necesidad de cambiar todo el proyecto actual).

Los creadores de Vue.js han tomado los mejores enfoques de Angular React y los han implementado en su Framework.

Es necesario preparar el ambiente de desarrollo instalando toda la infraestructura.
