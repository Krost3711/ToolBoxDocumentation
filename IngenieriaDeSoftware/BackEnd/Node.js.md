# Node.js (Especializado en el BackEnd)

## ¿ Que es Node.Js ?

Node.js es un entorno de ejecución para JavaScript que permite correr código fuera del navegador, especialmente en el lado del servidor. Es decir, con Node.js puedes usar JavaScript para construir aplicaciones backend, como APIs, servidores web, sistemas en tiempo real, y mucho más.

## Caracteristicas

- Asincronía y no bloqueo: Node.js maneja múltiples tareas al mismo tiempo sin detenerse a esperar que una termine

- En lugar de crear múltiples hilos, Node.js responde a eventos cuando ocurren, lo que lo hace muy eficiente.

- Normalmente es utilizado para:
- Crear APIs RESTful
- Servidores web y microservicios
- Aplicaciones en tiempo real (como chats o juegos)
- Automatización de tareas con scripts
- Backend de apps móviles o web
