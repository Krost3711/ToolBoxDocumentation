# Next.js (Full Stack de JavaScript)

## ¿ Que es Next.js ?

Es una Plataforma que viene a compensar todas las caracteristicas que React por si solo no tiene.
Se utiliza Java Script.

## Caracteristicas

Next.js ya tiene en su libreria un enrutador y muchas otras caracteristicas que React no tiene, ya que en React tenemos que implemetar la instalacion de diferentes paquetes con npm. Al ser un entorno Full Stack este ya tiene una serie de librerias internas necesarias para el desarrollo, sin necesidad de instalar dependencias externas.

Ahora bien Next.js, se apoya en Node.js, para poder ofrecer un Back End completo y asi poder llamarse Full Stack.

En Next.js gracias a que implementa codigo de Servidor, se puede utilizar para comunicarse con bibliotecas como MYSQL, POSTGRESQL, MONGODB. O usar ORM DE NEXT.JS como PRISMA, SEQUELIZE, MONGOOSE.
